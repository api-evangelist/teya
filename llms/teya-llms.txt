# Teya

> Teya is a European payments and business-services provider (formerly SaltPay) offering card machines, online payments, a business account, and lending to local businesses. Its developer platform exposes REST APIs for card acquiring — online/e-commerce payments, card-present and MOTO transactions, terminal (POSLink) control, dynamic currency conversion — plus SDKs for web and mobile point-of-sale integration. Authentication is OAuth 2.0 (authorization-code and client-credentials) against id.teya.com; write operations support Idempotency-Key.

## APIs

- [Online Payments API](https://docs.teya.com/apis/online-payments/apis): Hosted Checkout, PayByLink, e-commerce transactions, captures, refunds, digital receipts, tokens.
- [Payments Gateway API](https://docs.teya.com/apis/payments/overview): Card-present, MOTO, refunds, captures, reversals. Base https://api.teya.com.
- [POSLink API](https://docs.teya.com/apis/poslink/overview): Terminal payment requests, refunds, tabs, stores, terminals, ePOS registration, receipt printing.
- [Dynamic Currency Conversion (Teya FX) API](https://docs.teya.com/apis/dynamic-currency-conversion/overview): DCC offers and exchange rates. Scope fx/dcc/create.
- [Settlement API](https://docs.teya.com/reporting/introduction): SOAP/WCF settlement and payout reporting (Borgun endpoints).

## Auth

- Token endpoint (production): https://id.teya.com/oauth/v2/oauth-token
- Token endpoint (development): https://id.teya.xyz/oauth/v2/oauth-token
- API base (production): https://api.teya.com — (development): https://api.teya.xyz
- Flows: authorization_code, client_credentials. Header: Authorization: Bearer <token>. Idempotency-Key on writes.
